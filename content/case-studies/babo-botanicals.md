# Taking Back Control of a Store You No Longer Understood

---

## 01 — The Brand

Babo Botanicals is a family skincare and suncare brand that had grown far beyond the initial Shopify store it started with.

The original store had been built quickly and affordably by a freelance developer — a practical choice when the brand was starting out and budget was the top priority. But over years of growth, the store accumulated layers of custom code, quick fixes, and undocumented workarounds.

Then the developer stopped responding.

The website was still running, but the internal team no longer truly understood what was happening underneath it.

> **The store belonged to the brand. The code didn't feel like it did.**

---

## 02 — The Challenge

**Every small change had become an existential risk.**

The problem wasn't that the brand lacked features. It was that the team had become afraid to make changes at all.

- **01 — Fragile Interconnections**  
  A seemingly minor copy or theme update could break checkout or catalog filters because nobody understood how custom scripts were interconnected.
- **02 — Undocumented Technical Debt**  
  Years of quick fixes and third-party script injections had replaced proper architectural solutions.
- **03 — Developer Dependency**  
  Without the original developer available, there was zero documentation and no reliable technical roadmap.

The brand wasn't investing to improve its customer experience — **it was paying to avoid breaking it.**

![The Tech Debt Challenge — Undocumented code, fragile workarounds, and developer lock-in](/portfolio/babo-2.png)

---

## 03 — The Diagnosis

**The real problem was hiding underneath the storefront.**

Before changing a single line of production code, Technostripe needed to understand exactly how the store had been built. We conducted a forensic audit of the entire Shopify theme:

- **Undocumented Custom Liquid**  
  Discovered hundreds of orphaned snippets and hardcoded overrides conflicting with modern Shopify OS 2.0 standards.
- **Fragile Workarounds & App Scripts**  
  Identified legacy JavaScript libraries causing race conditions on product detail pages.
- **Unclear Architecture**  
  A technical foundation that evolved without version control or modular standards.

The goal wasn't to throw everything away. It was to separate what was working from what needed to be rebuilt properly.

![Shopify Theme Audit — Inspecting Liquid templates, snippets, and legacy scripts line by line](/portfolio/babo-5.png)

---

## 04 — The Strategy

**Rebuild the foundation before building anything new.**

Technostripe approached the project with one non-negotiable principle: **a Shopify store must be transparent and controllable by the brand.**

We structured our overhaul into four clear phases:

> **Audit** &rarr; Map every template, asset, and integration  
> **Simplify** &rarr; Strip away orphaned code and redundant apps  
> **Rebuild** &rarr; Modernize core sections with native Shopify architecture  
> **Document** &rarr; Equip the team with clear documentation and maintenance guides  

---

## 05 — What We Changed

### 01. Complete Theme Codebase Audit
We mapped every Liquid template, JSON template, and third-party script, documenting exactly how data and styles flowed across the store.

### 02. Custom Code Cleanup & Decoupling
We eliminated thousands of lines of redundant, conflicting JavaScript and CSS hacks. Theme functionality was re-anchored onto clean, modern Shopify conventions.

### 03. Native Architecture Rebuild
Where legacy hacks were holding back store speed and stability, we rebuilt features using native Shopify OS 2.0 theme app extensions and modular blocks.

![Streamlined Shopify Architecture — Structured backend allowing confident catalog and marketing management](/portfolio/babo-3.png)

### 04. Developer Handover & Documentation
We established version-controlled GitHub deployments and provided clear documentation so future updates would never again depend on an individual contractor.
